# Tic Tac Toe

A Tic Tac Toe game built with Vue 3, Vite, and Tailwind CSS.

## Run locally

Requires Node.js 22.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Create a production build with `pnpm build`, or serve it locally with `pnpm preview`.

## Deploy to GitHub Pages

The GitHub Actions workflow builds and deploys the site when changes are pushed to `master`. In the repository settings, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.
